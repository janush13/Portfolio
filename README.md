# Personal Portfolio Website 🚀

A modern personal portfolio website built to showcase my skills, projects, and frontend development journey.

## 📌 Project Overview

This portfolio website serves as a digital representation of my work as a Computer Science Engineering student and frontend developer.

It includes project showcases, personal information, and highlights my experience in building interactive web applications.

## ✨ Features

* 👨‍💻 Personal portfolio presentation
* 📂 Project showcase section
* 🌐 Responsive website design
* 🎨 Custom UI styling
* 📱 Mobile-friendly layout
* ⚡ Clean and simple user interface

## 🖥️ Projects Included

### 🧴 Crown Care

An AI-powered hair care application focused on personalized hair health solutions.

### 🎲 Dice Game

A simple interactive dice rolling game built to practice JavaScript logic and DOM manipulation.

### 🥁 Drum Kit

A fun interactive drum kit project demonstrating event handling and user interaction.
